# 🏛️ ЧИНОВНИКИ

## Язык программирования: C++

## 🎯 ЦЕЛЬ ПРОЕКТА

Разработка консольной программы для решения задачи «Чиновники», в которой необходимо определить минимальную стоимость получения лицензии с учётом иерархической структуры подчинения и стоимости получения подписи у каждого сотрудника министерства.

## 📦 ОПИСАНИЕ

Программа представляет собой консольное приложение на C++, работающее со структурой министерства, организованной в виде дерева.

Каждый чиновник имеет:
- уникальный номер (идентификатор);
- стоимость получения подписи (размер взятки);
- номер непосредственного начальника (0 для главного);
- список подчинённых (строится автоматически).

Правило получения лицензии: чтобы получить лицензию, предприниматель должен получить подпись главного чиновника. При этом каждый чиновник (включая главного) ставит свою подпись только при выполнении двух условий: (1) у него есть подпись хотя бы одного непосредственного подчинённого; (2) ему заплачена фиксированная сумма (взятка).

Задача программы:
- проверить корректность введённых данных;
- построить структуру министерства;
- найти минимальную сумму для получения лицензии;
- вывести оптимальную цепочку получения подписей.

## ✅ ФУНКЦИОНАЛ

Режимы ввода данных:
- ручной ввод с клавиатуры;
- загрузка из текстового файла;
- случайная генерация корректной структуры.

Проверки корректности:
- наличие ровно одного главного чиновника;
- отсутствие циклов в структуре подчинения;
- отсутствие ссылки чиновника на самого себя;
- допустимые диапазоны значений (N, взятки, номера начальников);
- корректность формата входного файла.

Основной алгоритм:
1. построение списков подчинённых для каждого чиновника;
2. рекурсивный обход дерева с мемоизацией (динамическое программирование);
3. выбор оптимального подчинённого с минимальной стоимостью продолжения;
4. восстановление и вывод цепочки подписей.

Вывод информации:
- общее количество чиновников;
- номер главного чиновника;
- таблица «номер → взятка, начальник»;
- древовидная структура министерства;
- выбранная цепочка подписей (снизу вверх);
- минимальная сумма в условных единицах.

Обработка ошибок:
- нечисловой ввод;
- значения вне допустимых диапазонов;
- отсутствие или неверный формат файла;
- логически некорректная структура министерства.

## ⌨️ ВВОД ДАННЫХ С КЛАВИАТУРЫ

При выборе пункта 1 программа последовательно запрашивает количество чиновников N (от 1 до 1000), затем для каждого чиновника - взятку (от 0 до 1000000) и номер начальника (0 - главный, иначе от 1 до N).

Пример для N=3:
Количество чиновников N: 3
Чиновник 1, взятка: 5
Чиновник 2, взятка: 2
Чиновник 3, взятка: 8
Чиновник 1, начальник: 0
Чиновник 2, начальник: 1
Чиновник 3, начальник: 1


## 📄 ФОРМАТ ВХОДНОГО ФАЙЛА

Файл должен содержать три строки:
N
взятка_1 взятка_2 ... взятка_N
начальник_1 начальник_2 ... начальник_N

Пример файла input.txt:
5
46 3 7 35 29
0 1 2 2 4

text

Пояснение: чиновник 1 - главный (начальник=0); чиновник 2 подчиняется 1; чиновники 3 и 4 подчиняются 2; чиновник 5 подчиняется 4.

## 🌳 ПРИМЕР СТРУКТУРЫ МИНИСТЕРСТВА

Для приведённого выше примера структура подчинения выглядит как дерево:
[1] (взятка=46)
└── [2] (взятка=3)
├── [3] (взятка=7)
└── [4] (взятка=35)
└── [5] (взятка=29)

## ⚠️ ОБРАБОТКА ОШИБОК

| Ситуация | Сообщение об ошибке |
|----------|---------------------|
| Ввод букв вместо числа | Ошибка: необходимо ввести целое число |
| Ввод дробного числа | Ошибка: введены лишние символы после числа |
| Число вне диапазона меню (0-4) | Ошибка: допустимый диапазон от 0 до 4 |
| N вне диапазона 1..1000 | Ошибка: допустимый диапазон от 1 до 1000 |
| Отрицательная взятка | Ошибка: допустимый диапазон от 0 до 1000000 |
| Чиновник - начальник сам себе | Ошибка: чиновник не может быть начальником самому себе |
| Два главных чиновника | Ошибка: главный чиновник уже был указан ранее |
| Нет главного чиновника | Ошибка: не указан главный чиновник |
| Цикл в начальниках | Ошибка: обнаружен цикл в структуре подчинения |
| Файл не найден | Ошибка: файл не найден или не может быть открыт |

При возникновении ошибки программа не завершается аварийно, а возвращает пользователя в главное меню.

## 💡 ПРИМЕЧАНИЯ

- количество чиновников (N): от 1 до 1000;
- главный чиновник: ровно один;
- структура: связное дерево (без циклов);
- стоимость подписи (взятка): от 0 до 1 000 000;
- нумерация: начинается с 1;
- начальник = 0 означает главного чиновника;
- у.е. - условные единицы;
- программа работает через консольный интерфейс;
- сохранение истории между запусками не предусмотрено.

## 🏁 ИТОГ

Программа позволяет:
1. построить структуру министерства из файла, ручного ввода или случайной генерации;
2. проверить корректность данных (главный чиновник, отсутствие циклов, допустимые значения);
3. визуализировать иерархию в виде дерева;
4. вычислить минимальную стоимость получения лицензии;
5. вывести оптимальный порядок получения подписей (от листа до корня).

Результатом работы программы являются минимальная сумма в условных единицах и цепочка чиновников для получения подписей.
